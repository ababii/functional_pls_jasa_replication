# Data: `corn.csv` & `soybeans.csv`

**Contents**  
This folder contains a zip archive with two datasets generated by the Jupyter notebook:
- `data.zip` → `corn.csv`, `soybeans.csv`
- `data_cleaning.ipynb` (notebook that generated the CSVs)

**Provenance**  
The CSVs were created by running `data_cleaning.ipynb`. The original raw data were compiled from publicly available sources and are distributed in the Schlenker & Roberts (2009) replication package:  
https://www.wolfram-schlenker.info/replicationFiles/SchlenkerRoberts2009.zip
