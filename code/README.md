# Reproducibility Notebooks

This folder contains two Jupyter notebooks with Python and Julia code to reproduce the results of  
**“Functional Partial Least-Squares: Adaptive Estimation and Inference”** (Babii, Carrasco, Tsafack),  
*Journal of the American Statistical Association, Theory and Methods* (forthcoming).

## Contents
- `empirical_application.ipynb` (Python) — empirical results using the cleaned data.
- `simulations.ipynb` (Julia) — Monte Carlo experiments.

**Run**  
Open each notebook and run all cells top-to-bottom (see the first cell for dependencies).
